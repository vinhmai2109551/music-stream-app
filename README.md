# Music Stream

A music streaming mobile app built with Expo, React Native and TypeScript for a university mobile course project.

## Getting started

```bash
npm install
npx expo start
```

Scan the QR code with Expo Go (Android / iOS).

## Scripts

| Script              | Description       |
| ------------------- | ----------------- |
| `npm run lint`      | ESLint            |
| `npm run lint:fix`  | ESLint with fixes |
| `npm run format`    | Prettier          |
| `npm run typecheck` | `tsc --noEmit`    |
